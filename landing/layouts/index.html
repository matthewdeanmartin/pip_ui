A GUI THAT SHOWS ITS WORK

From choice to command, in plain sight.

Use the interface to learn the CLI while keeping control over the target environment and working directory.

01 / TARGET

Pick an interpreter

Discover available Python installations and project environments, then choose the one a command should use.

02 / PREVIEW

Browse a tool’s command tree. Options become controls, and the complete argv stays visible before execution.

Read streaming output and exit status. Copy the command into a script or return to its recorded history.

BUILT-IN GUARDRAILS

See what changes before it changes.

Read-only commands stay easy to run. Risky operations are classified, global installs are flagged, and --safe-mode asks for confirmation before destructive or configuration-changing actions. Secret-bearing flags are redacted from history and output.
